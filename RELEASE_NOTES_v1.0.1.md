# CAS Curator v1.0.1

CAS Curator v1.0.1 substantially expands the organisation, review and routing workflow around the established CAS scanner while keeping the **frozen scanner core unchanged**.

## Recommended download

Use **`CAS_Curator_v1.0.1_Installer.zip`** for the normal Windows installation.

The installer:

- lets you choose the installation folder and drive;
- can create a Desktop shortcut;
- adds Start Menu and uninstall support;
- uses the CAS Curator application icon throughout;
- confirms when installation has completed;
- can launch CAS Curator immediately after setup.

Users who prefer a portable build can use **`CAS_Curator_v1.0.1_APP.zip`** instead.

## Highlights

- Added Profile Rules that remember each Profile's filter view and visible Table columns.
- Improved Profile Membership and added Experimental Profile Layouts with explicit Planned Locations.
- Added preflight and rollback safeguards for Apply Profile Locations.
- Added the Experimental Routing Structure Builder with reusable folder structures, preview, sanitising and transactional routing.
- Added managed File Locations and safer routing/recovery location updates.
- Added universal **+ Add Quick Filter…** support alongside Status / CC Type / Creator.
- Added Creator and Converter metadata and improved package web-search shortcuts.
- Added persistent column visibility controls, collapsible column shortcuts and smoother horizontal Table navigation.
- Added a hideable Details panel and compact Gallery quick-filter toolbar.
- Added Age/Gender plus opt-in Advanced and Experimental metadata views.
- Improved Scanner Log resizing, dialogs, theme readability, Tools organisation and the built-in Guide.
- Added **About CAS Curator…**, Copy version info and source/support shortcuts.

Additional convenience tools include copying selected packages to a configured CC Magic Import folder, ZIP preview/extraction, and conservative Sims3Pack scan intake.

## Safety and compatibility

- The frozen scanner core remains unchanged.
- Run Scan does not move source files.
- Routing and Profile Location moves remain explicit user actions.
- Experimental scanner-derived metadata never automatically controls Routing.
- Profile Rules and selecting/filtering a Profile never move package files.
- Copying selected packages to the configured CC Magic Import folder uses copies and does not replace the organised master package.
- ZIP is the supported archive preview/extract format; RAR and 7Z are not supported.
