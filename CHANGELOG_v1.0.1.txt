CAS CURATOR v1.0.1 — CHANGES SINCE v1.0
==========================================


Library and organisation

- Added a simpler Status workflow with In Game Use, To Keep, To Review, or blank.
- Added File Location management so packages can be linked to named folders, opened directly in Explorer, and moved between managed locations with identity/hash checks and rollback safeguards.
- CAS Curator now records the new File Location after successful routing, and restores safely matched locations when Recover Last Routing puts files back.
- Improved Profiles with compact assignment controls, Manage Profiles, and multi-select Merge Profiles support.
- Added a manual Creator field. Creator can be edited per package, filled for several selected packages at once, searched, filtered, and used by the package/creator web-search shortcuts.
- Added a universal + Add Filter… system. Extra filters can be stacked together, support conditions such as *is*, *contains*, *is blank* and *is not blank*, and work alongside Search and the permanent Status / CC Type / Creator / Profile filters.
- Added compact CAS / Health / Organise column show/hide shortcuts while keeping the full Columns chooser for individual columns.
- Column visibility choices persist between sessions.
- Added safer Table editing tools including fill-down for displayed rows and guarded Delete Record handling. Deleting an MDB record does not delete the physical package file.
- Added package right-click shortcuts including Open File Location, Search Web for Package, and Search Web for Creator when a Creator is available.


CC Magic Import

- Added a separate, configurable CC Magic Import destination.
- Copy Selected to CC Magic Import… is copy-only: the organised master package remains in place and its File Location is not changed.
- Added a live, read-only CC Magic Import status that reflects the real Import folder, including states such as in Import, not in Import and conflict.
- CC Magic Import status can be used with + Add Filter… and refreshes after copy operations and external folder changes.
- Once CC Magic processes content out of the Import folder, use CC Magic itself to manage or remove it; CAS Curator does not delete files from CC Magic-managed storage.


Scan and archive intake

- Added ZIP preview/extract support. ZIPs can be inspected before extraction, unsafe paths are rejected, existing files are not overwritten, and the original ZIP is kept.
- When ZIPs are found during Run Scan, CAS Curator can extract them beside the original archives first so newly extracted packages join the same scan.
- Added conservative Sims3Pack analysis during Scan. CAS Curator reads the manifest without modifying the original Sims3Pack.
- CASpart Sims3Packs can optionally have missing embedded CAS package copies extracted beside the original. Exact standalone duplicates are detected by SHA-256 and are not extracted again.
- Multi-part CAS Sims3Packs are handled as one set, with each embedded package checked separately and missing parts extracted together.
- Lots, worlds, Sims/households, patterns, objects and unknown/mixed Sims3Packs remain protected and packed for normal intact routing.
- Added a pre-scan MDB compatibility check for workbooks containing spreadsheet-specific OOXML extensions that the scanner cannot safely parse. CAS Curator can create and verify a separate compatible copy while leaving the original workbook untouched.
- Normal Run Scan no longer asks for an unnecessary generic Yes/No confirmation after validation. Decision prompts still appear when a real choice is required, such as ZIP/Sims3Pack handling or MDB compatibility.
- Scan progress now has a finalising stage so 100% is reached only when saving/refreshing is complete, and a large completion/log window no longer opens automatically.


Routing and safety

- Added a pre-routing scan-state check that distinguishes packages that are Ready, Changed since scan / not verifiable, or Not in MDB.
- When attention is required, the warning itself is the decision point: Run Scan First, Continue Routing Anyway, or Cancel. Continuing no longer produces a second duplicate confirmation.
- Successful routing now records exact routed locations back to safely matched MDB rows.
- Recover Last Routing restores safely matched File Location values together with the recovered files.
- Fixed image passthrough routing so images retain the selected source-folder name under IMAGES rather than being flattened directly into the IMAGES root.
- Added an Open folder shortcut beside the configured Sort destination.


Metadata and review tools

- Age and Gender are now normal read-only metadata derived from direct CASP observations when available.
- CASP linking is more resilient for older/routed records by falling back to direct CASP Instance IDs when the package-name link is stale.
- Added opt-in Advanced features for trusted technical fields such as Biggest Texture, HQ Warning, Poly Warning, textual Risk, Duplicate Files, CASP Instance IDs, Health Issues, Last Scanned and Package Hash.
- Added opt-in Experimental features for provisional Subtype, Skin Type, Outfit Category and EA Resource Status information.
- Experimental fields are display/review aids only. They do not automatically control Routing or modify package files.
- Package Format can appear in Overview when available without adding another sparse Table column.


Interface and readability

- General UI polish improved resizing, layout consistency, readability and theme behaviour across Library, Scan, Guide and supporting windows.
- Library is now the single place to create, open or change the active Master Database. Scan shows that same MDB read-only and always writes to it.
- Improved dialog handling for long messages and Windows paths, with more consistent sizing, wrapping and centring.
- Added the teal-green CAS Curator package/check application icon for the title bar/taskbar.
- Updated the Guide and simplified Manual fields help to reflect the current workflows in plain language.

Compatibility and safety notes

- The frozen scanner core remains unchanged by these additions.
- Existing routing classification decisions remain conservative; new Experimental metadata never changes Routing automatically.
- Managed locations are explicit actions only — CAS Curator does not add background folder watching or automatic movement.
- ZIP is the supported archive preview/extract format; RAR and 7Z are not supported.
- CC Magic Import remains a deployment-copy workflow and is deliberately separate from the master package's File Location.
